# Replace images

1. Put your files inside `public/images/projects/` or `public/images/profile/`.
2. Open `src/data/projects.ts`.
3. Replace an image URL with a local path, for example:

```ts
image: "/images/projects/my-project-cover.webp"
```

For the About image, edit `workspaceImage` in `src/data/site.ts`.
